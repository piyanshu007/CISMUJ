## 🚨 Reporting a Vulnerability

The IEEE CIS MUJ technical team takes security and data integrity seriously. If you discover a security vulnerability or potential threat in this repository or its deployed instances:

1. **Do NOT open a public GitHub issue.**
2. Email your findings directly to the chapter technical leads at:  
   **`cis.muj@ieee.org`** with the subject line `[SECURITY] Vulnerability Report - <Summary>`.
3. Include detailed reproduction steps, potential impact, and suggested remediations if available.

### What to Expect:
- **Acknowledgement**: Within 48 hours of initial report receipt.
- **Assessment**: We will validate the issue and determine severity and affected components.
- **Resolution**: A coordinated patch will be developed, tested, and deployed to production.
